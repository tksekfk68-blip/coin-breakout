# 코인 레이더

업비트 원화마켓 거래대금 상위 30개 코인을 대상으로 **추세 돌파 신호**를 찾고, 그 신호가 과거에 얼마나 맞았는지 백테스트하는 웹입니다.

## 신호 조건 (일봉, 세 가지 모두)
1. 종가가 직전 20일 최고가를 넘음
2. 20일 이동평균 > 60일 이동평균
3. 거래대금이 직전 20일 평균의 2배 이상

## 상태 표시
🔥 돌파 · 🎯 눌림목(돌파 후 지지선에서 거래량 줄며 양봉 반등) · ⏳ 눌림 대기 · 👀 돌파 임박 · ⚠️ 과열 · 🧊 하락 추세 · ⏸ 관망

지지/저항은 최근 120일 고점·저점을 ±2.5% 가격대로 묶어 여러 번 부딪힌 곳을 표시합니다. 손절 기준은 돌파 가격 또는 지지선 -3%.

## 화면
- **오늘의 신호**: 실시간 시세(업비트 웹소켓), 어제 마감 기준 판정, 오늘 진행 중 돌파 여부, 차트
- **백테스트**: 기간/채점 시점/돌파 기준/거래량 배수/손절을 바꿔가며 적중률·평균 수익·손익비 확인. "아무 날이나 샀을 때"와 비교
- **실전 성적표**: 매일 09:05(KST) 자동 저장된 신호를 이후 가격으로 채점

## 구조
```
public/            화면 (index.html, app.js, style.css)
public/lib/        전략·백테스트 엔진 (브라우저·서버 공용)
netlify/functions/ upbit(시세 중계) · daily-log(매일 자동 기록) · log-now(수동 기록) · track(성적표)
netlify/lib/       서버 공용 코드
```

## 넷리파이 배포
1. app.netlify.com → **Add new project → Import an existing project → GitHub** → `coin-breakout` 선택
2. 설정은 그대로 두고 **Deploy** (netlify.toml이 알아서 잡아줌)
3. 배포 후 `https://<사이트주소>/api/log-now` 를 한 번 열면 첫 기록이 저장됨

투자 권유가 아니며, 과거 성적이 미래 수익을 보장하지 않습니다.
